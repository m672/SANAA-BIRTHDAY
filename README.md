# Birthday sanaaa — Netlify-ready site

افتح `index.html` محليًا أو ارفع المجلد كاملًا إلى Netlify. الموقع لا يحتاج إلى build step؛ كل الملفات ثابتة (`HTML/CSS/JS`) والصور موجودة داخل `assets/`.

## الرفع على Netlify

1. فك ضغط الملف المضغوط.
2. ارفع مجلد `birthday-sanaa-site` إلى Netlify Drop، أو ارفع ملف الـ RAR بعد فكّه محليًا.
3. لا تغيّر أسماء الملفات أو مجلد `assets`.

يدعم الموقع أزرار السابق/التالي، النقاط، أسهم لوحة المفاتيح، والسحب على الموبايل، مع انتقالات متحركة مناسبة لعيد الميلاد.

تمت إضافة `assets/birthday-video.mp4` داخل الشاشة الرابعة بجانب صورة الشاشة، مع الحفاظ على جميع الصور الأصلية. الصور تستخدم عرضًا كاملًا بدون قص، والتصميم متجاوب مع الموبايل واللاب.
